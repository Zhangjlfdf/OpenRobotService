# archive/ — 历史归档（仅供追溯，勿当现行口径）

本目录收纳 automation 测试框架演进过程中**已完成使命的一次性过程产物**。
它们记录了当时的决策背景与实施过程，有一定追溯价值，但**不代表当前系统行为或当前规范**。

## 内容分区

| 路径 | 内容 | 说明 |
|------|------|------|
| `worklog/` | `task-NN-*.md` 按任务编号的开发记录 | 早期流水账式 worklog，任务编号存在重复（task-21/22 各两份） |
| `design-*.md` | 各阶段设计稿 | 多数头部标注「设计稿待确认」，对应功能**已实施或已废弃** |
| `gap-analysis-*.md` | 测试缺口分析快照 | 某次针对 PRD / skill 的差距分析，结论已消化 |
| `ci-ai-test-pipeline.md` | AI 用例生成流水线早期设计 | 代码引用见 `automation/ci_ai_gen/__init__.py`（已更新指向本目录） |
| `design-implementation.md` | 早期实施方案 | 已被后续设计取代 |

## 纪律

- **新增的现行设计请放 `automation/docs/` 顶层**，不要放本目录。
- 现行有效文档见 `automation/docs/README.md` 的「顶层文档」表。
- 本目录文件**不再维护**；如需复活某份设计，请复制到 `docs/` 顶层并重写为现行口径。
